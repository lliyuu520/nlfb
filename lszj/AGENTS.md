# AGENTS.md

> 《怒雷风暴》(Nu-Thunder) 个人微信小游戏项目规范

## 项目目标
开发一款竖版街机飞行射击小游戏，通过微信小游戏平台发布，利用激励视频广告（复活/金币翻倍，玩家主动触发）实现个人变现；不做常驻 Banner 等损伤体验的展示广告（2026-09-06 产品决策）。

## 架构原则
- **游戏渲染层**：基于 `wx.createCanvas()` 的 Canvas 2D 高频绘制（核心玩法）。
- **界面层**：视觉上需脱离传统“Web 文字绘制”感，通过图形绘制、UI 图标化和更细腻的布局提升质感。
- **环境隔离**：完全兼容微信小游戏 API，禁用 DOM/BOM API。

## 开发规范
1. **输入处理**：使用 `wx.onTouchStart/Move/End`，逻辑需适配移动端触控，UI 需支持触摸点击（炸弹按钮、复活确认）。
2. **状态管理**：使用显式状态机（Title/Playing/Over/Clear），确保逻辑可预测。
3. **性能控制**：严格控制每帧开销，避免过多的 `ctx.fillText`，必要时采用位图数字渲染。
4. **适配**：强制竖屏配置（`portrait`）。

## 必须遵守的决策阶梯 (Ponytail)
1. **YAGNI**：暂不引入复杂的第三方游戏引擎（如 Cocos/Laya），维持原生 Canvas 实现以保证最短路径上线。
2. **标准化**：所有 API 调用需在 `js/main.js` 中通过微信标准接口实现。
3. **反馈**：所有交互必须有视觉/触觉反馈，拒绝 HTML 风格的极简文字布局。

## 验证门禁
- 每次 UI 修改后需触发 `wechatide` CLI 进行真机模拟器预览。
- 重点检查：触控响应延迟、HUD 遮挡视线问题、广告接口调用安全性。
