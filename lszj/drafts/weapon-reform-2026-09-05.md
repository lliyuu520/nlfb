## 0. 一句话目标

把现有"3 主 + 2 副"扩到雷电式的"3 主 + 3 副 + 4 条灵魂机制"，**最大缺口是等离子激光**（雷电 II 的灵魂），其次是 Nuclear 直射导弹与"切换规则"。

## 1. 雷电武器谱系（参考源）

整理自西武 / Moss 历代资料：

| 槽位 | 雷电 1 / 2 | 雷电 3 | 雷电 4 / 5 | 核心特征 |
|---|---|---|---|---|
| 主·红 | Vulcan 火神炮 | Vulcan | Vulcan | 散弹·面覆盖·升级加弹道 |
| 主·蓝 | Laser 激光 | Laser | Laser | 窄光束·穿透·升级加宽 |
| 主·紫/绿 | Plasma 等离子（雷 2） | Proton Laser（雷 3） | Plasma 回归 | 弯曲/锁定/摆动 |
| 副·M | Nuclear 直射导弹 | Nuclear | Nuclear | 高爆溅射 |
| 副·H | Homing 追踪 | Homing | Homing | 追踪·快·伤害低 |
| 副·R | — | Radar 雷达 | Radar | 半追踪·先横后直 |
| 副·P | Photon 光子（雷 5） | — | — | 穿透激光 |

**雷电原谱的"灵魂规则"**（Rice Digital 等多源确认）：
1. **同色升级**：捡到当前主武器同色道具 → 火力等级 +1（弹道/光束变粗变密）
2. **异色平切**：捡到不同色道具 → **保持当前等级切换武器**（不升级也不掉级）
3. **死亡掉级**：死一次火力等级 -1（惩罚不归零）
4. **光束随移动摆动**（Proton Laser ±45°）：把"走位"变成"瞄准"

## 3. 改造方案 v1

### 3.1 主武器 3 种（保留 std/homing/laser + 新增 plasma）

```
主武器        颜色   等级形态                  伤害       特殊
─────────────────────────────────────────────────────────────
std 机炮      黄     1/2/3/4 → 1/2/3/5 路扇形    1×lv       （升级改弹道形态）
homing 追踪   橙     1/2/3/4 → 散射箭头          1.5        （保留）
laser 激光    青     1/2/3/4 → 单束加宽          2+lv×0.5   （升级改光束宽度，仿 Proton）
plasma 等离子 紫 🆕  1/2/3/4 → 单束弯曲锁定      2+lv       【新增】0.35s 同目标→锁定，DoT
```

**形态化升级的关键**：等级提升不是单纯加数值，而是**改变视觉/命中形态**——这才有"升了一级能感觉到"的满足感，也避免雷电后期"高等级=数值碾压"的疲劳。

### 3.2 副武器 3 种（新增 nuclear，保留另两）

```
副武器        颜色   行为                      伤害       特殊
─────────────────────────────────────────────────────────────
homing 追踪   黄     mlevel+1 发追踪           3          （保留）
laser 副炮    紫     sp 1100 穿透              2+mlv      （保留，可作 plasma 解锁素材）
nuclear 直射  橙 🆕  2 发 + 横向扩散 + 命中溅射  4          【新增】对单体补爆发
```

**Nuclear 关键设计**：发射时一左一右散开、再向正前方收回，命中产生半径 ~20 的溅射伤害。这是雷电 Nuclear Missile 的核心——让"宽幅武器也能打单体"。

### 3.3 四大灵魂机制改造

| # | 机制 | 改法 | 改哪 |
|---|---|---|---|
| M1 | **异色平切** | 同色 +1 级，**异色保持等级不升级不降级** | main.js:445 |
| M2 | **光束摆动** | laser / plasma 发射角度 = 自机横向速度方向 ±18°（钳上限） | main.js:395, 417 |
| M3 | **等离子锁定弯曲** | 命中同一目标 0.35s → 进入锁定态，光束用 `quadraticCurveTo` 弯向该目标，路径上的其他敌机也受伤；目标死亡则光束回直重新选目标 | main.js:394, 401（新增分支 + 新增 `beams` 数组） |
| M4 | **死亡全槽掉级** | `wlevel-1` + 新增 `mlevel-1`（已 partial 实现，扩到位） | main.js:584 |

### 3.4 持续光束的实现要点（重要技术决策）

**不要把光束塞进 `bullets` 数组**。理由：
- 现在机炮 1 级 1 发/0.09s = 11 发/s；激光 1 发/0.11s = 9 发/s。状态机 50 个子弹就够 Canvas 2D 吃紧。
- 等离子是**单条持续光束**（不是一颗颗子弹），每帧判定"线段 vs 圆"，命中一次就算。
- 弯曲光束用多段折线/贝塞尔绘制，命中检测走"光束起点→中控点→终点"三次线段-圆判定。

新增顶层数组 `beams=[]`，结构：

```js
beams.push({
  x: p.x, y: p.y - 26,           // 起点
  cx: p.x, cy: p.y - 200,        // 控制点（弯曲时随锁定目标偏移）
  tx: p.x, ty: -20,              // 终点
  color: '#c77dff',
  w: 6,                          // 光束宽度
  weapon: 'plasma',              // 区分 laser / plasma
  locked: null,                  // 锁定目标 id；null 表示未锁定
  lockT: 0,                      // 同目标持续时间，>0.35s 进入锁定
  pierce: true,
  dmg: 2 + p.wlevel,
  hits: new Set(),
  ang: 0,                        // 当前摆角（基于自机横向速度）
});
```

每帧 update：
1. 根据 `player.x` 与上一帧 x 差计算摆角 ang（钳 ±18°）
2. 若有锁定目标 → 更新终点到目标中心，控制点偏移到光束中点侧方
3. 否则控制点 = 起点 + 方向 × 200
4. 沿曲线做 5~8 段"线段-圆"判定，命中减血 + pierce 记录
5. 出屏回收

绘制：复用现有 `laserSprite`（main.js 已有，竖向胶囊）按 angle 旋转后 drawImage；若锁定态，每帧重画时角度由 cx/cy 算出（弯曲效果自然生成）。

### 3.5 掉落循环与推荐搭配

**道具颜色循环**（仿雷电 1）：红→蓝→紫→红→…（紫=plasma，需先解锁）。

**等离子解锁条件**：玩家首次通关 OR 累计拾取副炮激光达 5 次（紫光束的研究资料？）。这是手游的常见节奏控制——保证新武器不是开局就拿。

**推荐搭配 HUD 提示**：在 HUD 第二行文字末尾加 1~2 字搭配建议（如"散弹·核"），把"主+副"组合的玩法教给玩家。

## 5. 风险点 & 老板拍板项

| 风险 / 决策 | 影响 | 建议 |
|---|---|---|
| 等离子过强会破坏难度曲线 | 高 | P0+P1 上线后实测，调 dmg / 锁定时间 |
| 弯曲光束低端机掉帧 | 中 | 5~8 段折线已属保守；预留回退到 3 段 |

| 等离子解锁条件 | 中 | 推荐"首通关解锁"，节奏最自然 |
