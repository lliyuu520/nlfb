## 0. 目标与验收

**目标**：新增第 3 种主武器 `plasma`（紫色）——单条持续光束，命中同一敌机 0.35s 后弯曲钉住该目标持续掉血，路径上的其他敌机也受伤。

**验收标准**：
1. 拾取紫色道具切换到 plasma，同色再拾取 wlevel +1（走 P0 的新规则）
2. 光束随自机横向移动摆动，幅度 ≤ ±18°
3. 同一目标持续照射 0.35s 后光束弯曲锁定，目标死亡后回直
4. 弯曲态下路径敌机同样掉血
5. 微信开发者工具 + 真机各跑一遍：弹幕密集期帧率不明显下跌（目标 ≥ 50fps）
6. `node --check js/main.js` 通过

**解锁条件（已拍板）**：玩家**首次通关**后解锁 plasma，掉落表中才会出现紫色 plasma 道具；未解锁前紫色掉落替换为加分道具。

## 1. 数据结构

新增顶层数组（与 `bullets` 平级，**不塞进 bullets**）：

```js
const beams=[]; // 等离子光束（玩家最多 1 条，数组留扩展余地）
```

光束对象结构：

```js
{
  x: p.x, y: p.y - 26,           // 起点（机头）
  cx: p.x, cy: p.y - 200,        // 贝塞尔控制点（锁定时偏向锁定目标侧）
  tx: p.x, ty: -20,              // 终点（屏幕顶）
  color: '#c77dff',
  w: 6,                          // 光束宽度，随 wlevel 5/6/7/9
  locked: null,                  // 锁定目标引用（enemy 对象）；null=未锁定
  lockT: 0,                      // 同一目标累计照射时间
  lockId: null,                  // 上一帧命中的目标 id（判断"同一目标"）
  ang: 0,                        // 当前摆角（由自机横向速度驱动，钳 ±18°≈0.314 rad）
  dmg: 2 + p.wlevel,             // 每跳伤害
  hitT: 0,                       // 伤害跳表计时（0.1s 一跳，见 §3）
}
```

**关键决策——伤害节流**：光束是持续照射，若每帧都结算伤害，DPS = 60帧 × dmg，瞬间融怪。改为 **0.1s 一跳**（hitT 累计，`hitT>=0.1` 时结算并清零），lv1 DPS = 20，与机炮 lv1（11发/s × 1 ≈ 11）相比略高，符合"高难度操作武器"定位。

## 2. 分步实施

### 2.1 解锁标记（~15 行）

- `gameClear()`（通关结算处）：`try{wx.setStorageSync('nlfb_plasma_unlocked',1)}catch(e){}`
- `dropItem()`（main.js:415）：紫色分支前查 `wx.getStorageSync('nlfb_plasma_unlocked')`，未解锁时紫色改为加分道具（kind:'score'）
- 掉落表（main.js:424-430 附近）：`roll` 落在紫区 → `{color:'#c77dff',letter:'P',kind:'w',val:'plasma'}`

### 2.2 发射入口（~10 行）

`firePlayer()`（main.js:383 附近）最前面加分支：

```js
if(p.weapon==='plasma'){ firePlasma(dt); return; }
```

`firePlasma` 不是"每帧 push 子弹"，而是**维持单例光束**：若 `beams` 已有本玩家的光束则只更新 dmg/w，否则 push 新光束。切枪（拾取异色道具）或死亡时清空 `beams`。

### 2.3 update（~50 行，核心）

在 `update(dt)` 的子弹循环后新增 `updateBeams(dt)`：

1. **摆角**：`targetAng = clamp((p.x - prevPx) / dt * 0.0004, -0.314, 0.314)`，`ang += (targetAng-ang)*Math.min(1,dt*12)`（平滑追随，避免手抖光束狂甩）
2. **锁定判定**：本跳命中的第一个敌人 `lockId` 与上一帧相同 → `lockT += dt`；`lockT >= 0.35` 且目标存活 → `locked = 目标`；目标换人/死亡 → `lockT=0, locked=null`
3. **端点更新**：
   - 未锁定：终点 = 起点 + 方向（ang 旋转后）× 屏幕外距离，控制点 = 中点
   - 锁定：终点 = 目标中心；控制点 = 起点与终点中点 + 垂直偏移（偏移量 = 光束长 × 0.18 × 锁定侧），产生"甩尾弯曲"视觉
4. **命中检测**：沿贝塞尔取 8 个采样点，相邻采样点连线做**线段-圆**判定（圆 = 敌机 r+光束半宽）。命中即入本跳命中集
5. **伤害结算**：`hitT += dt; if(hitT>=0.1){ 对命中集每个敌人 hitEnemy(e,dmg); hitT=0; 命中集清空 }`。穿透天然成立（光束不消失）
6. **回收**：切枪 / 死亡 / `p.weapon!=='plasma'` → `beams.length=0`

### 2.4 绘制（~30 行）

在子弹绘制循环后新增 `drawBeams()`：

- 未锁定：以 `(x,y)` 为原点旋转 `ang`，复用 `laserSprite`（main.js 已有竖向胶囊）纵向拉长画一条；宽度按 `w` 缩放
- 锁定态：`ctx.beginPath(); moveTo(起点); quadraticCurveTo(cx,cy,tx,ty);` 用 `strokeStyle=color, lineWidth=w` 加一层外发光（浅色同色低透明度再 stroke 一次，宽 ×2.2），**不用 shadowBlur**（真机软光栅，见 main.js:592 现有注释的经验）
- 锁定目标处画命中光斑（复用 `spark` 每 0.1s 冒 2~3 个粒子即可，不新增粒子逻辑）

### 2.5 HUD 与文案（~10 行）

- `WPN_ZH`（或等价的中文名表）加 `plasma:'等离子'`
- 战机分级面板/首页展示解锁条件："等离子激光：首次通关解锁"

### 2.6 素材（可选后置）

- 掉落图标：`ITEM_IMG` 先用 `letter:'P'` + 紫色底兜底；后续 ImageGen 出"掉落物-04"
- 光束本体不需要贴图，绘制全靠 laserSprite + stroke

## 5. 风险与回退

| 风险 | 缓解 |
|---|---|
| 弯曲光束低端机掉帧 | 采样 8 点 + 无 shadowBlur 已保守；备选回退 5 段采样 |
| 锁定切换频繁导致光束抖动 | lockId 平滑追随（ang 同款插值） |
| plasma 过强破坏曲线 | 锁定加成 ×1.2 与 0.35s 前摇是真机后主要调节旋钮 |
| wx storage 异常（少见机型） | 所有 set/getStorageSync 包 try-catch，失败视为未解锁（仅影响解锁展示，不崩溃） |

回退方案：出问题时把 `dropItem` 紫区分支还原（1 行），plasma 变成不可达武器，光束代码零调用零开销，无需回滚整个版本。
