构图 B 改了什么
· 面板 320×590 @ y62 → 400×800 @ y120（居中，底部留白 388 → 120，避开顶部 64 安全区与底部 48 手势条）
· 卡间距 12 → 24；固定项 74×66 间距 4 → 81×76 间距 12；刷新↔出战 10 → 12；翻倍条 36 → 44 高（全部满足 ≥44×44 热区）
· 新增「本局构筑」条：把 over 页已有的「构筑 N 张 · 最强牌×n」前移到商店，玩家随时看得见自己这套是什么流派
· 代价：卡宽 290 → 360、图标块 50 → 54，现有切图与 drawShop 坐标需整体重排，工作量大于画板一

落地差异（已按本构图改 main.js 后回写）
· 44×44 是逻辑 px：游戏设计宽固定 480，在 390 逻辑 px 机型上 1 设计 px≈0.81 逻辑 px，翻倍条 44 / 按钮 48 设计 px 实际只有 36~39 逻辑 px。故视觉高度不变，命中矩形按设备补足到 44 逻辑 px（main.js 的 SHOP_HIT_H / shopHit）
· 买不起锁形 right 36 → 46：36 时与右上角稀有度角标压边重叠
· 25 个霓虹线稿图标尚未产出，图标块暂沿用单汉字（攻/速/盾…），稀有度底色与斜纹底块保留
· 网格/斜纹底纹与真外发光未进代码（shadowBlur 在真机软光栅掉帧），改用外圈宽描边低透明度 + 内圈窄描边实色模拟霓虹光边（ui.js drawChamferPanel）
· 「本局构筑 N」的 N 是拿牌数（runPicks），右侧格子按牌型去重显示，两者在重复拿同一张牌时并不相等 → 标签补「张」单位，与结算页「构筑 N 张」口径一致
