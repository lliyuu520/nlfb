## 一、游戏概况

《怒雷风暴》:竖屏街机弹幕射击(雷电味)+ 局内肉鸽构筑(土豆兄弟式补给站)。玩家拖动战机躲弹幕、击杀敌机拾取金币袋,Boss 通关后进"补给站"用金币多轮购牌/升级,构筑流派推进更高关卡。

**风格关键词**:霓虹赛博 · 街机复古 · 深空科幻 · 高对比发光 · 硬边几何
**情绪基调**:爽快、压迫感(Boss 弹幕)、决策紧张感(补给站花钱)

## 二、技术硬约束(设计稿必须遵守)

| 约束 | 值 |
|---|---|
| 画布逻辑宽 | 固定 480px,高度自适应 800~1200(主流设计稿按 480×1040 出) |
| 方向 | 强制竖屏 |
| 刘海/安全区 | 顶部预留 ~64px(状态栏+胶囊按钮区,右上角有微信胶囊不可放置功能元素);底部预留 ~48px 手势条 |
| 最小触摸热区 | 44×44 逻辑 px(按钮间距 ≥12px,相邻卡间距 ≥24px) |
| 渲染性能 | 元素数量克制;大面积阴影/模糊慎用(真机软光栅会掉帧);文字为等宽字体渲染,设计稿请用等宽字体表达数据类文字 |
| 无 DOM | 一切视觉皆为"画在画布上的图",设计稿需给出可整图导出的完整组件 |
| 资源形式 | 图标/实体最终以 PNG 精灵交付(透明底),界面底框/进度条可程序绘制,设计稿说明配色与圆角描边规格即可 |
| 最小字号 | **10px 是硬下限**(低于此真机 CJK 笔画粘连,见 `main.js` SFS 注释);补给站按面板缩放后仍钳在 10px |

补充说明(源自代码实测,设计稿需按此设定而非凭感觉):

- **禁用 shadowBlur**:真机软光栅下 `shadowBlur` 直接掉帧。发光一律用「外圈宽描边低透明度 + 内圈窄描边实色」两层描边模拟(已实现于 `ui.js` `drawChamferPanel`)。现存 `drawNeonPanel` / `drawBossBar` / 战斗 HUD 仍在用 shadowBlur,属**待淘汰旧组件**,重设计时一并换掉。
- **基础形是 45° 硬边切角**,不是圆角(`ui.js` `chamferPath`)。设计稿的面板/卡片/角标请统一用切角,圆角只在明确指定处使用。
- **受击白闪走 `globalCompositeOperation='lighter'` 叠绘**:实体素材若自带大面积高亮底色,叠绘后会糊成白块。实体主体请压在中等明度,高光只做点缀。

## 三、全局视觉语言(现状 token,可在此基调上重设)

- 主色:霓虹青 `#00f3ff`(主按钮/面板描边)
- 强调金:`#ffd23c` / `#ffe600`(金币、稀有、警告)
- 危险红:`#ff0055` / `#ff5d5d`(游戏结束、敌人、警告横幅)
- 生命绿:`#7dff8c`(通关、可购买、血条健康)
- 底色:深空 `#05050c`~`#0a0e1e`,三层视差星空背景
- 面板样式:深底(85% 不透明)+ 2px 霓虹描边 + 外发光 + 四角装饰线(现有 drawNeonPanel,可重设计)
- 字体:等宽 monospace(数字对齐),标题粗体大字+发光

### 执行原则(2026-09-07 补充:身份保留霓虹街机,执行层面现代化)

上方 token 描述的是现状;以下四条为全部设计稿的验收标准,凡违反直接打回:

1. **发光收敛**:面板一律实色填充 + 细描边(1~2px);外发光仅限关键交互元素(出战/复活主按钮、价格数字、Boss 警告横幅)。禁大面积 glow,禁 CRT 扫描线/噪点滤镜(真机软光栅性能与视觉过时双重原因)。
2. **色彩分级**:底色与面板底退到中性深蓝灰,霓虹四色降级为点缀色;同屏只有一个主"喊话色"(补给站=金、战斗=青、危险态=红),其余信息靠亮度与留白分层,不靠发光。
3. **字体分工**:数字(分数/价格/倒计时)保持等宽位图风;中文标签一律现代无衬线体(系统黑体一档);标题做字形设计本身,不靠发光堆质感。
4. **亮度分层**:弹幕与玩法实体最亮 > HUD 次亮 > 面板背景最暗,保障弹幕可读性(命中判定公平性优先)。

基调差异:战斗内保留霓虹爽感;补给站/设置/结算等决策界面可读性优先,向土豆兄弟(Brotato)式实色卡片靠拢。整体规避"黑底满屏霓虹+金字"的低质买量页既视感(微信大盘休闲用户敏感)。

基准稿:`drafts/ui/shop-station-B-proposal.png`——全 UI 以此稿的克制程度为基准推广;现有标题屏(满屏描边发光+扫描线)即为需淘汰的反例。

## 四、界面清单与逐屏要求

### 4.1 标题屏(title)

现有元素:游戏 Logo 文字"怒雷风暴"、副标题"赛博街机 · 弹幕射击"、左上"排行"、中上"声音"开关、右上"设置"、中央星空、底部"▶ 点击屏幕开始战斗 ◀"、最高分。
设计要求:
- Logo 需要一个真正的 **游戏标题字形设计**(现为主字体+发光,希望有金属/霓虹字形的标识感)
- 突出"点击开始"的呼吸感引导(当前为闪烁文字)
- 排行榜/声音/设置三个入口的图标化按钮(现为文字+边框)

### 4.2 战斗 HUD(最重要的常驻层)

自上而下四行信息区(安全区下方,总高约 76px,不得下侵玩法区):
| 区域 | 内容 | 现状 |
|---|---|---|
| 行1 左 | "得分"标签 + 7 位大数字 | 文字,需数字字体设计(可考虑位图数字) |
| 行1 中 | "第 N 关" + Boss 倒计时"NN秒"/"首领!!"(精英出场时为"精英!!") | 文字闪烁 |
| 行1 右 | 金币 `¥ N`(金色) | 文字 |
| 行2 左 | 武器名+等级(如"武器 机炮 2级") | 文字 |
| 行2 右 | **血条**:96×10px 条 + `HP/上限` 数字(绿>35%→黄>18%→红) | 程序条,需血条样式设计(分段?斜切?装甲感?) |
| 行1 左外 | 静音小喇叭(战斗中,位于得分左侧) | 程序绘制 |
| Boss 战 | 底部 Boss 血条(全宽渐变条)+ 顶部"警告·首领接近"横幅(闪烁) | 需横幅与 Boss 血条设计 |

设计要求:HUD 必须轻,不遮挡弹幕视野;信息层级"分数>血>金币>武器";金色货币与青色系统信息形成双色调。

### 4.3 补给站(shop)——**本次重设计的核心界面**

出现时机:每关 Boss 通关动画后,全屏暗化+中央面板;玩家用局内金币消费后点"出战"进下一关。
面板内容(自上而下):
1. 标题"补给站·第 N 关"(金色面板)
2. 金币余额大字 `¥ N` + 副信息"本关收入 +N(·已翻倍)"
3. **随机强化牌 ×3**(纵向大卡,每卡 360×96,设计基准为 400×800 面板内坐标,非全屏 480):左侧 54×54 图标块(稀有度底色)、名称+"Lv 当前/满级"、一行效果描述、右下角价格 `¥ N`(买得起金色/买不起粉色,买不起整卡置灰)
4. **固定升级项 ×4**(横排小卡,每卡 81×76):主炮强化(¥ 动态)/激光改造(¥150)/导弹吊舱(¥ 动态)/战场维修(¥50,满血置灰"—");可购买绿描边、不可用灰、满级"—"
5. 按钮行:左"▶ 看广告 免费刷新"(用后变"刷新 ¥N")/ 右"出 战 ▶"(绿色主按钮)
6. 底部:"▶ 看广告 本关金币翻倍 +N"(已翻倍置灰)
7. 最底部:**本局构筑摘要行**——"本局构筑 N 张" + 7 格构筑图标(等宽降序取前 7)+"最强 牌名 ×n"(青色低调面板,给下一关"我现在的流派"一个可读摘要)

设计要求:
- **这是留存核心界面,要有"逛商店的愉悦"**:卡牌要有牌感(边框质感、稀有度差异一眼可辨、可购买与买不起状态差异强)
- 稀有度视觉体系:普通 N(青 `#00f3ff`)/ 稀有 R(金 `#ffd23c`)/ 核心(品红 `#ff4dd2`)**三档**,图标块+边框+价格色三重表达;核心牌每局限 1 张、单价 300 起,需要"远处一眼就认出这是攒钱目标"的辨识度
- 购买力三态已实现,设计稿需给出对应视觉:**可买**(实色描边+发光)/ **差一点**(余额≥55%,粉色描边 + 进度条 + "差 ¥N · 击杀敌机补足")/ **完全买不起**(灰描边 + 锁形图标,但保留稀有度色相不掉档)
- 价格是核心信息,购买力状态(买得起/差一点/完全买不起)希望有清晰的视觉梯度
- 卡图标目前为"单汉字色块"占位,**需要 20 张牌图标 + 4 个固定项图标**(见第六节清单)

### 4.4 通关动画(clear,2.4 秒)

"战区肃清"面板 + "通关成功"大字 + "第 N 关通过·得分 N"。2.4 秒后自动切补给站。设计要求:短促爽快的庆祝视觉(文字动效为主),无需按钮。

### 4.5 游戏结束(over)

面板"最终战报":游戏结束大字(红)、得分、最高分、"剩余金币 N · 存款 +M(已翻倍)"、按钮:复活机会 N·▶ 看广告复活(青)/重新开始(红)/▶ 看广告 存款翻倍(金);面板下方一行"构筑 N 张 · 最强牌×n"。
设计要求:失败但不绝望(鼓励再来一局),复活按钮是核心变现入口需最醒目。

### 4.6 暂停菜单(pause)

"已暂停"小面板 + 三按钮:继续游戏(青)/重新开始(红)/回到标题(黄)。设计要求:轻量,半透明暗化背景。

### 4.7 设置页(settings,独立全屏页)

左侧竖排 Tab 菜单:玩法/战机/背景/强化/声音/关于(6 项,每项 48px 高、间距 8px,内容区内边距 16px);右侧内容区滚动。Tab 选中态各有主题色:玩法青/战机青/背景绿/强化金/声音粉/关于紫。
- 玩法:TIPS 操作说明列表
- 战机:3 款机体涂装选择(怒雷号免费/赤焰号¥800/幽紫号¥1500),预览+购买
- 主题:3 款星空配色(深空蓝/星云紫/翡翠绿)
- 强化:局外金币强化 2 项(掉落率 max5/火力强度 max5,等级价递增)
- 声音:音效/BGM 开关
- 关于:版本号/说明
设计要求:菜单-内容双栏布局的样式设计;金币余额常显;购买按钮状态(已拥有/可买/钱不够)。

### 4.8 排行榜(rank,独立面板)

好友榜/世界榜双 Tab,名次列表(头像/昵称/分数),自己的名次高亮。当前为 openDataContext 渲染,样式可设计后对接。

## 八、素材交付对接表(现有 CDN 命名与实际绘制尺寸)

CDN 加载规则(`js/cdn.js`):URL = `https://oss.lliyuu520.cn/sprites/<素材名>.png`,**素材名即文件名(不含扩展名),URL 必须保持稳定**——加版本号 query 会让 CDN 缓存命中率归零。更新流程是「覆盖 OSS 同名文件 + 调 CDN 刷新接口」,所以**新稿必须沿用下表命名**,否则要改代码。
