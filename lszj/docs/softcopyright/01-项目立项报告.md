# 怒雷风暴小游戏软件 V1.0 项目立项报告

**阶段**：项目立项阶段　　**日期**：2026-08-20

## 一、项目背景

微信小游戏平台用户基数大、即点即玩、无需下载安装，适合个人开发者以轻量休闲游戏切入，并通过激励视频广告与 Banner 广告实现变现。开发者拟基于已有的《怒雷风暴》H5 飞行射击原型，迁移至微信小游戏平台并扩展完整玩法。

## 二、项目定位

- **产品名称**：怒雷风暴（Nu-Thunder）
- **类型**：竖版街机飞行射击小游戏（STG）
- **目标用户**：利用碎片时间游玩的移动端休闲玩家
- **核心体验**：单手拖动操控、自动射击、Boss 战与道具成长带来的即时爽快感
- **商业模式**：激励视频广告（战败复活）+ Banner 广告（底部展示），无内购

## 三、可行性分析

| 维度 | 结论 |
|------|------|
| 技术 | 采用微信小游戏原生 Canvas 2D 渲染，不引入 Cocos/Laya 等第三方引擎，代码量可控（预计 800 行以内），单人可完成 |
| 性能 | 竖屏 480×800 设计分辨率，逐帧绘制对象数量有限，中低端机型可稳定运行 |
| 素材 | 音效采用 WebAudio 振荡器实时合成，无需外部音频资源；UI 以图形化绘制实现，无需大量图片素材 |
| 合规 | 广告调用走微信标准接口并做失败降级；个人主体可凭软件著作权证书申请游戏类目（广告变现、无内购） |

## 四、立项结论

项目可行，立项通过。计划 2026 年 9 月上旬完成开发与测试，随后申请软件著作权并提交微信平台审核发布。
