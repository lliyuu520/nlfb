# 怒雷风暴小游戏软件 V1.0 软件测试报告

**阶段**：软件测试阶段　　**日期**：2026-09-04

## 一、测试环境

微信开发者工具模拟器（多机型分辨率：含刘海屏与非刘海屏）+ 真机预览（Android / iOS）。

## 二、测试项与结果

| 测试项 | 用例要点 | 结果 |
|--------|---------|------|
| 触控与坐标换算 | 多分辨率下拖动位置与战机实际位置一致 | 通过 |
| 触控响应延迟 | 移动、炸弹按钮、复活按钮即时响应，无明显延迟 | 通过 |
| 炸弹按钮触控区 | 右下角圆盘随 Banner 高度上移后仍可准确点击 | 通过 |
| 复活流程 | 广告完整观看→复活成功；未看完/加载失败→提示且不复活；2 次上限后不再显示复活按钮 | 通过 |
| 广告降级 | 广告接口不可用时提示"广告暂不可用"，游戏流程不中断 | 通过 |
| 刘海屏安全区 | HUD 避让摄像头/状态栏，玩家可移动上边界不遮挡血条 | 通过 |
| Banner 避让 | 玩家与底部控件不与 Banner 重叠 | 通过 |
| 音效降级 | 不支持 WebAudio 的环境静默运行，不报错 | 通过 |
| 核心玩法 | 武器/道具升级、Boss 战、通关进阶、结算与重开流程 | 通过 |
| 性能 | 模拟器与真机满帧运行，无卡顿明显波动 | 通过 |

## 三、缺陷记录与修复

- 开发中发现残留 PC 键盘映射对象导致报错，已修复（提交 11:50）；
- 刘海屏 HUD 与玩家上边界遮挡问题，已按 safeArea 修复（提交 13:48）；
- 炸弹按钮触控区与 Banner 重叠问题，已随触控区对齐修复（提交 13:38）。

## 四、测试结论

全部测试项通过，遗留缺陷为零，具备提审发布条件。
