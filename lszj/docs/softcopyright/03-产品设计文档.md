# 怒雷风暴小游戏软件 V1.0 产品设计文档

**阶段**：产品设计阶段　　**日期**：2026-08-25

## 一、玩法设计

- **操控**：手指拖动屏幕控制战机移动（位置映射至 480×800 逻辑坐标系），战机自动射击，玩家专注走位躲避。
- **状态机**：Title（标题）→ Playing（进行中）→ Over（战败结算）/ Clear（通关），状态切换清晰，战败可复活或重开。
- **判定方式**：战机核心采用小判定点（中心小白点），符合弹幕游戏"擦弹"体验。

## 二、数值设计

| 模块 | 设计值 |
|------|--------|
| 主武器 | 标准弹 std / 穿透激光 laser / 追踪 homing，火力等级 Lv.1~Lv.4，激光射速 0.11s、标准弹 0.09s |
| 副武器 | 追踪导弹 / 激光导弹，等级 Lv.1~Lv.3，发射间隔 0.5s |
| Boss | 开局 65 秒后出现；血量公式 260 + 140×当前关卡；弹幕随关卡增强 |
| 敌机波次 | 刷怪间隔由 1.6s 随时间与关卡压缩至最低 0.55s；敌机速度 120 + 12×关卡 |
| 生命与炸弹 | 初始生命 3 条、炸弹 3 枚；炸弹全屏清弹并清除敌方弹幕；受击后 2 秒无敌 |
| 复活 | 单局最多观看 2 次激励视频复活，复活保留当前得分与关卡进度 |

## 三、道具设计

击毁敌机概率掉落：**R**（切换追踪导弹）、**B**（切换穿透激光）、**P**（副武器火力升级），拾取半径 22px，有音效与武器等级提升反馈。

## 四、流程设计

单局内：刷怪 → 65 秒 Boss 战 → 击败 Boss 通关 → 进入下一关（关卡无限递进，难度抬升）。战败时弹出结算面板：剩余复活次数则显示"看广告复活 / 重新开始"双按钮，否则仅"重新开始"。
