# 怒雷风暴小游戏软件 V1.0 技术方案设计说明书

**阶段**：技术方案设计阶段　　**日期**：2026-08-30

## 一、技术选型

- **平台**：微信小游戏（基础库 ≥2.19.0，支持 `wx.createWebAudioContext`）。
- **渲染**：`wx.createCanvas()` 原生 Canvas 2D 逐帧绘制，不引入 Cocos/Laya 等第三方引擎，保证包体最小化与实现可控性。
- **语言**：JavaScript（严格模式），模块化 `require` 组织。

## 二、模块架构

| 文件 | 职责 |
|------|------|
| `game.js` | 小游戏入口，引入主模块 |
| `game.json` | 平台配置（竖屏 portrait） |
| `js/main.js` | 主逻辑：状态机、实体系统、碰撞、绘制调度 |
| `js/ui.js` | 霓虹面板/按钮等 UI 绘制封装 |
| `js/loop.js` | 主循环与帧计时 |
| `js/ads.js` | Banner 与激励视频广告封装（含失败降级） |

## 三、关键技术方案

- **坐标系**：设计分辨率 480×800，触摸事件 `clientX/Y` 经窗口尺寸换算映射至游戏坐标；
- **安全区**：优先取 `wx.getWindowInfo()`（基础库 2.20+，回退 `getSystemInfoSync()`）的 `safeArea/statusBarHeight`；顶部刘海/挖孔与状态栏取二者较大值换算为 `safeTop`，确定 HUD 起始高度与玩家可移动上界；底部手势条换算为 `safeBottom`，与 Banner 实际高度取大值得到 `bottomInset`，炸弹按钮、Boss 血条、标题页底部文案、设置/排行榜面板均按此动态上移避让；
- **音效**：WebAudio 振荡器（方波/三角波滑音）与白噪声缓冲实时合成射击、爆炸音效，不支持时静默降级，零音频素材；
- **状态机**：`title/playing/over/clear` 显式状态切换，输入处理按状态分发；
- **存储**：`wx.getStorageSync` 持久化历史最高分；
- **广告**：Banner 常驻底部；复活走 `wx.createRewardedVideoAd`，按 `onClose` 回调的完整观看标记决定是否复活，加载失败给出 Toast 降级。

## 四、性能方案

控制每帧 `fillText` 数量、粒子与实体数组按帧回收、绘制前统一缩放变换一次完成，保障中低端机型满帧运行。
