# 怒雷风暴小游戏软件 V1.0 需求调研与产品规划说明书

**阶段**：需求调研与产品规划阶段　　**日期**：2026-08-22

## 一、竞品与用户调研

- **竞品分析**：微信小游戏平台内同类飞行射击产品（如飞机大战、雷电类游戏）普遍采用"单指拖动 + 自动射击 + 定时 Boss 关"的成熟模式，验证了该玩法在小屏触控设备上的可行性。
- **用户需求**：碎片时间即开即玩；单手可操作；死亡后有挽回手段（复活）以延长单局体验；成长反馈直观（武器升级、火力变化肉眼可见）。

## 二、功能需求清单

1. 标题引导与状态管理（标题/进行中/结算/通关四态切换），标题页展示操作引导与历史最高分；
2. 触控拖动操控战机，自动发射弹幕；
3. 武器系统：标准弹、穿透激光、追踪三类主武器（最高四级火力），追踪导弹/激光导弹副武器（最高三级）；
4. 道具掉落与拾取升级（R 追踪导弹、B 穿透激光、P 火力升级）；
5. 多关卡循环递进，敌机波次随关卡增强，每关定时出现 Boss；
6. 全屏清弹高能炸弹（右下角按钮触发）；
7. 三条生命与受击无敌时间；
8. 战败后观看激励视频广告复活（单局上限 2 次）；
9. Banner 广告与激励视频广告接入，含加载失败降级提示；
10. 本地最高分存储；实时合成音效；霓虹风 HUD 与结算/通关界面。

## 三、非功能需求

- **性能**：严格控制每帧绘制开销，减少 `fillText` 频次；适配中低端机型。
- **适配**：竖屏（portrait）强制；适配刘海屏/状态栏安全区；底部控件避让 Banner 高度。
- **合规**：全部 API 使用微信小游戏标准接口，禁用 DOM/BOM；广告调用必须容错。

## 四、里程碑规划

需求调研与产品规划 → 产品设计 → UI/UE 设计 → 技术方案设计 → 代码开发 → 软件测试 → 上线部署，目标 2026 年 9 月上旬具备提审条件。
