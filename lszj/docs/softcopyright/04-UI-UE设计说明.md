# 怒雷风暴小游戏软件 V1.0 UI/UE 设计说明

**阶段**：UI/UE 设计阶段　　**日期**：2026-08-28

## 一、视觉风格

采用**霓虹科技风**：深空底色 + 高饱和霓虹描边（青、黄、紫），面板使用"全息玻璃"质感（半透明底 + 发光边框），标题与血条做科幻光效处理，整体脱离传统 Web 文字界面的"网页感"。

## 二、布局与适配

- **画布**：竖屏 480×800 设计分辨率，按设备像素等比缩放绘制。
- **HUD 顶部区**：得分、最高分、关卡（STAGE）、Boss 出现倒计时、武器类型与等级、高能血条；HUD 起始位置按设备 `safeArea` 向下避让刘海/摄像头与信号状态栏。
- **炸弹按钮**：屏幕右下角霓虹圆盘，随底部 Banner 广告高度自动上移，触控判定区不小于手指热区要求。
- **玩家活动边界**：顶部让开 HUD 区域，底部让开 Banner 区域，避免误触与遮挡。

## 三、交互与反馈

- 所有交互均有即时视觉反馈（按钮按下态、拾取道具音效、受击震屏与闪白、爆炸粒子）；
- 结算/通关面板使用统一霓虹面板样式，复活按钮实时显示剩余次数（如 REVIVE 2）；
- 标题页提供操作引导文案（拖动移动、自动射击、炸弹按钮、道具说明、核心判定点提示）。

## 四、界面清单

标题页、游戏中 HUD、战败结算面板（含复活）、通关面板、广告加载提示（LOADING...）、广告不可用 Toast 提示。
